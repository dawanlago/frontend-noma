# frontend-noma

Interface do Noma CRM. Next.js (Page Router) + TypeScript + Tailwind.

A UI é em português. Variáveis e arquivos estão em inglês.

## Rodar

Na raiz do monorepo, o backend precisa estar no ar em `http://localhost:3333`.

```bash
cp .env.example .env.local
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
